## Independent 1-Command On-Chain Verification

Anyone can independently verify the live Base Mainnet (`8453`) deployment, runtime bytecode hashes, documentation integrity, and roadmap evidence directly against Base RPC with zero third-party dependencies:

```bash
git clone https://github.com/NARAProtocol/nara_protocol.git
cd nara_protocol
npm ci
npm run verify
BASE_RPC_URL=https://base-rpc.publicnode.com npm run verify:onchain
```
